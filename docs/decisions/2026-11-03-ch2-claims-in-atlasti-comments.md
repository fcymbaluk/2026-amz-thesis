# 2026-11-03 — Chapter 2: the one-line claim is written in ATLAS.ti, not in the Zotero comment

**Context.** The codebook of 2026-10-18 and the workflow decision of
2026-10-20 placed the one-line claim of each quotation in the Zotero
highlight comment, carried into ATLAS.ti by the importer. The first
real import (*The Last Forest*, 152 highlights, 2026-11-03) showed the
practice: one highlight in 152 had a comment. Highlighting while reading
and formulating the claim are different acts, and the second belongs
with the coding.

**Decision.** The claim is written in ATLAS.ti, as the quotation
comment, above the provenance line the importer leaves there, in the
same pass as the codes. A Zotero comment is optional and, when present,
is carried over by the importer as before. The codebook's vocabulary
(63 codes in nine families besides the four dimension codes) was
created in the project `2026-amz-ch2` on the same day, with the
definitions as code comments and a folder and group per family, so the
coding pass has everything in one tool.

**Rationale.** Zotero stays the reading tool (highlight and color);
ATLAS.ti is where the quotation is read in context, coded and
annotated. Splitting the claim off into Zotero made it an interruption
of reading, which is why it was not written. The export path is
unchanged: the quotation table carries the comment either way.

**Consequences.** `ch2-historical/coding/codebook.md` (intro,
per-highlight procedure, import mechanics, new paragraph "Codes in
ATLAS.ti") and `ch2-historical/GUIDANCE.md` (checklist item, evidence
rules) updated in the same commit. The importer is unchanged. Claims
for the 152 `london2007` quotations are written during their coding.
